# Decisions Log

Append-only chronology of project decisions. ADRs and GDDs are source of truth; this log is index + context for cross-cutting decisions and process choices.

## Format

```
## [YYYY-MM-DD HH:MM] — [Topic]

**Type**: design | architecture | scope | process | gate
**Context**: [1 sentence — what triggered the decision]
**Decision**: [what was decided]
**Rationale**: [why]
**Refs**: [links to ADR / GDD / EPIC.md / playtest / sprint-status]
**Decided by**: [human / agent name]
```

## Rules

- Append-only. Never edit past entries; supersede with a new entry referencing the old one.
- Entries written by `/ags-gate-check`, `/ags-epic-retro`, `/ags-architecture-decision`, and on any human-approved scope or process change.
- Refs must be relative paths inside the repo.
